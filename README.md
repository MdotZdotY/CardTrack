# 卡点时光 - 微信小程序

## 项目简介

卡点时光是一款专门为个人消费者管理各类多次消费套餐卡的微信小程序，解决用户忘记使用次数和过期浪费的痛点。

## 主要功能

### 核心功能
- **套餐卡管理**：添加、编辑、删除各类套餐卡
- **使用记录**：记录每次使用，自动计算剩余次数
- **到期提醒**：智能提醒即将到期的套餐卡
- **数据统计**：查看使用情况和消费统计

### 特色功能
- **拍照录入**：拍照识别套餐卡信息
- **智能提醒**：个性化提醒设置
- **数据备份**：云端备份和恢复
- **分享功能**：分享给朋友或朋友圈

## 技术架构

### 前端技术
- **框架**：微信小程序原生开发
- **样式**：WXSS + 自定义组件
- **逻辑**：JavaScript ES5语法

### 后端服务
- **存储**：微信云开发
- **数据库**：云数据库
- **文件存储**：云存储

## 开发环境

### 环境要求
- 微信开发者工具 1.06.2504010+
- Node.js 14.0+
- 微信小程序基础库 2.19.4+

### 安装步骤
1. 克隆项目到本地
2. 使用微信开发者工具打开项目
3. 配置AppID（在project.config.json中）
4. 编译运行

## 配置说明

### 基础配置
- **AppID**：在微信公众平台申请的小程序ID
- **项目名称**：卡点时光
- **版本号**：v1.0.0

### 功能配置
- **云开发**：需要开通微信云开发服务
- **存储配置**：配置云存储和数据库权限
- **API配置**：配置相关API接口

## 使用说明

### 添加套餐卡
1. 点击首页"+"按钮
2. 填写卡片信息（名称、商家、分类等）
3. 设置总次数和已用次数
4. 选择到期日期
5. 保存卡片

### 记录使用
1. 在卡片列表中找到要使用的卡片
2. 点击"记录使用"按钮
3. 确认使用次数
4. 系统自动更新剩余次数

### 查看统计
1. 进入设置页面
2. 查看使用统计
3. 了解消费情况
