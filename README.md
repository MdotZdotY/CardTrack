# 卡点 - 套餐卡管理小程序

## 项目简介

卡点是一款专门为个人消费者管理各类多次消费套餐卡的微信小程序，解决用户忘记使用次数和过期浪费的痛点。

## 核心功能

### V1.0 版本功能
- ✅ 套餐卡管理（增删改查）
- ✅ 使用次数记录和撤销
- ✅ 到期提醒系统
- ✅ 分类管理
- ✅ 本地数据存储
- ✅ 统计信息展示

### 计划功能
- 🔄 云端数据同步（V1.1）
- 🔄 使用统计图表（V1.1）
- 🔄 分享给家人功能（V1.1）
- 🔄 拍照录入功能（V1.2）
- 🔄 附近商家推荐（V2.0）

## 技术架构

### 设计理念
采用**策略模式 + 分层架构**设计，确保V1.0快速上线，V1.1无缝升级：

```
┌─────────────────────────────────────┐
│           用户界面层 (UI)            │
├─────────────────────────────────────┤
│          业务逻辑层 (Service)         │
├─────────────────────────────────────┤
│           数据模型层 (Model)          │
├─────────────────────────────────────┤
│         存储抽象层 (Storage)          │
├─────────────────────────────────────┤
│      存储策略层 (Strategy Pattern)     │
│  ┌─────────┐ ┌─────────┐ ┌─────────┐ │
│  │ 本地存储 │ │ 云端存储 │ │ 混合存储 │ │
│  └─────────┘ └─────────┘ └─────────┘ │
└─────────────────────────────────────┘
```

### 技术栈
- **前端**: 微信小程序原生开发
- **存储**: V1.0本地存储 → V1.1混合存储
- **架构**: 策略模式 + 分层架构
- **设计**: 现代简约风格，橙色主色调

## 核心模块说明

### 存储抽象层
- **StorageManager**: 存储管理器，支持策略切换
- **LocalStorageStrategy**: V1.0本地存储实现
- **CloudStorageStrategy**: V1.1云端存储实现（待开发）
- **HybridStorageStrategy**: V1.1混合存储实现（待开发）

### 数据模型
- **Card**: 套餐卡数据模型，包含业务逻辑方法
- **UsageRecord**: 使用记录数据模型

### 业务服务
- **CardService**: 套餐卡业务逻辑处理
- **NotificationManager**: 通知和提醒管理
